Test steps (manual E2E)
  1. Login as a patient and a nurse (Postman/curl with dev OTP — no SMS needed) and paste both JWTs below.
  2. Nurse: paste nurse JWT above, click Connect with role NURSE, then Go Available (writes Redis presence — stays fresh ~90s via heartbeat).
  3. Fill Profile ID (patient's) + Service Type ID, then 1 · Create Request → 2 · Nearby Nurses (expect the nurse in the list).
  4. 3 · Create Offer (nurse token) → 4 · Accept Offer.
  5. 5 · Get Visit Code (the code the UI would render as a QR) → 6 · Complete Visit (nurse token).
  6. Subscribe to the reservation topic to see OFFER_CREATED / OFFER_ACCEPTED / COMPLETED events live.
  7. Negative checks: Try Wrong Code → expect 400; repeat step 6 twice → second one should 400.
